# API de Agendamento

API REST para agendamento de serviços (barbearia), feita com Java e Spring Boot.

## Tecnologias
Java 21, Spring Boot 3, Maven

## Como rodar
1. Clone o repositório
2. Execute `./mvnw spring-boot:run`
3. Acesse http://localhost:8080/status
